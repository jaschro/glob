The code is available under the Apache 2.0 license, but the model weights have a separate NVIDIA research license. You'll also need to check the hardware requirements and model-license terms before setting it up. 
The main limitation: Lyra 2.0 currently focuses on static environments. It isn't a complete, physically accurate simulation of a living world, and generated geometry can contain artifacts. 
My take: Lyra 2.0 is significant because it combines generative AI with persistent 3D structure. That could make creating explorable environments much easier, particularly for robotics, virtual production and immersive visualization. It is not yet a substitute for a fully modeled, physically accurate 3D environment.
One useful comparison would be with Marble from World Labs, which pursues a similar goal of creating explorable 3D worlds from images and prompts. The two are worth comparing if you're interested in what you can actually create today.
